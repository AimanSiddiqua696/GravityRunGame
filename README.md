# 🎮 Evasion Protocol

A feature-rich 2D desktop game developed in **C#** using **Windows Forms**, built on a reusable object-oriented game framework. The project demonstrates advanced software engineering principles, including modular architecture, reusable components, event-driven programming, collision detection, animation, sound management, and persistent game progress.

---

## 📖 Overview

**Evasion Protocol** is a survival-based 2D game where the player must navigate through increasingly difficult levels while avoiding obstacles, collecting points, and surviving enemy encounters. The game was built using a custom reusable framework designed for extensibility and maintainability.

This project was developed as part of the **Object-Oriented Programming (OOP)** course and successfully fulfills all framework and game development requirements.

---

## ✨ Features

### 🎮 Gameplay
- Three fully playable levels with increasing difficulty
- Player health system with health bar
- Real-time scoring system
- Main menu and game options
- Persistent game progress using file handling
- Collision detection
- Interactive game objects
- Smooth player controls
- Responsive gameplay mechanics

### 🧩 Reusable Game Framework
- Configurable movement system
- Horizontal Patrol
- Vertical Patrol
- Zig-Zag Movement
- Jump Movement
- Follow Player (Chasing AI)
- Random Patrol Movement

### 🎨 Animation System
- Frame-based animations
- Idle animation
- Movement animation
- Death animation
- Reusable animation component

### 🔊 Sound System
- Background music
- Sound effects
- Event-driven sound triggering
- Simultaneous sound playback

### 💾 File Handling
- Save player score
- Save completed level
- Save game progress
- Persistent game data

# 📚 Academic Context

This project was developed as part of the **Object-Oriented Programming (OOP)** course at the **University of Engineering and Technology (UET), Lahore**.

The assignment required students to first design a reusable game framework and then build a complete game using that framework. The framework includes reusable movement systems, animation, sound management, configurable game objects, and persistent game progress.
